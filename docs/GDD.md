# ШТОРМОВИЙ РИБАЛ (Storm Fishers) — GDD / Дизайн-документ

> Версія 1.0 (MVP). Мова інтерфейсу — українська.
> Платформа: сучасний браузер (Chrome/Edge/Firefox/Safari). Tech: Vite + TypeScript + Three.js.
> Спосіб розгортання: статичний `dist/` (або `npm run dev` локально).

---

## 1. Еліфт (elevator pitch)

Ты — капітан невеликого рибальського човна «Шторм» у північному морі. Ти сам ходиш по палубі,
керуєш барраком, ловиш рибу, ладиш двигун, вариш улов, слухаєш радіо і переживаєш шторми.
Плавне, «жирне» морське симуляційне ядро + цикли порту: продай → прокачай → вийди далі в море.

**Референси:** *Stormworks* (вільне ходіння по палубі, станції, прокачка) + *Windward*
(симуляція мореходності, хвилі) + *Fishing Sim World* (цикл лову) + *Raft* (рутина на палубі).
Відмінність: плавність (кільцева хвиля + м'яка фізика), краса (Gerstner-оcean, day/night, погода)
і економічна петля без бою з NPC.

## 2. Цілі та петлі

### Цілі гравця
1. **Короткострокова:** зловити рибу → повернутися в порт → продати → купити пальне/апгрейд.
2. **Середньострокова:** покращити човен до 5-го рівня, відкрити всіх видів риби («Рибальський довідник»).
3. **Довгострокова:** накопичити 25 000 ₴ і стати «Капітаном північного моря» (фінальна мета; далі — бескінечна гра).

### Основна петля (5–25 хв реального часу)
```
Порт (паливо, ремонт, продаж, апгрейди)
   → Вихід у море (вибір зони: узбережжя / середина / відкрите море)
   → Ловля + рутини (двигун, кухня, радіо, обсушка палуби, сон)
   → Погіршення погоди? → рішення: тягнути далі або дістати до дому
   → Повернення, продаж, прибуток
```

## 3. Стиль (art direction)

- **Настрій:** «золота рибальська доба» — тепле сонце, білий пінок, ржавий човен, гудіння мотора.
- **Палітра:** океан — глибокий синьо-бірюзовий; небо — від лимонадно-жовтого сходу до індиго ночі;
  човен — оксамитово-червона обшивка + білий дах; порт — дерево + синьо-білі будинки, маяк.
- **Графіка:** low-poly + PBR-матеріали + сильне світло/тінь; Gerstner-хвилі з піникою на гребенях,
  сонячний блиск, fresnel; туман за горизонтом; зоряне небо і місяць вночі; дощ і блискавки в шторм.
- **Кам'яність/«жирність» (game feel):** спрайтки бризок при швидкості, гуркіт мотора, гойдання
  камери від хвилі, спрайк при лові, «хруст» блискавки, плавно-м'яке гойдання човна без дрифу.
- **UI:** темне скло (glassmorphism), округлі картки, акцент — бірюза `#37c6b5` і сонячний `#ffb454`;
  шрифт системний, великі чіткі цифри; промпти дій знизу по центру.

## 4. Механіки

### 4.1 Човен та фізика
- Рігідне тіло: положення/швидкість, yaw/pitch/roll, кутова швидкість.
- **Буївність:** сітка 5×3 точок по днищу. Кожна точка порівнюється з функцією хвилі;
  занурена глибина → вертикальна сила (м'яко, без дрифу) + гальмування у воді.
  Моменти від розподілу сил → природне гойдання та крен.
- **Двигун:** тяга від газу (W/S у штурвалі), витрата палива ∝ газу × навантаження;
  рильє (A/D) працює від притоку води. Без газу — човен дрейфує з вітром і хвилями.
- **Скорості:** базове 34 км/д (з апгрейдом до ~55 км/д). Топ-швидкість обмежується потужністю/хвилями.
- **Корпус:** міцність 0–100. Удар об мілини/буї/пірси знімає міцність; міцність 0 → затоплення
  (рятувальний катер, штраф 300 ₴, втрата 30 % утримувача).
- **Палуба затоплюється** великими хвилями в шторм → «обсушити палубу» (станція помпи);
  мокра палуба → менша плавучість і ефективність мотора.

### 4.2 Гравець
- First-person на палубі (WASD + миша, Shift — біг, E — дія, Esc — пауза).
- Можна вийти за борт → **плавання** у воді (голова над хвилями), E біля борта — залізти назад.
- У порту можна сойти на причал: магазин, заправка, ремонт, хата (сон безкоштовно).
- **Енергія 0–100:** дії станцій її витрачають; сон відновлює; при 0 — дії недоступні.

### 4.3 Станції на човні (рутина в тишу!)
| Станція | Місце | Дія |
|---|---|---|
| Штурвал | носа | газ/рильє керування човном |
| Трюм-рибалка | корма | закинути вудку, ловити |
| Двигунна | правий борт | ремонт корпусу, тюнінг (+ефективність, зносить) |
| Кухня | біля кабіни | варити сиру рибу → «варена» (+50 % ціни) |
| Радіо | кабіна | прогноз погоди + звіти про рибу в зонах |
| Койка | кабіна | сон → прискорений час до світанку, енергія 100 |
| Помпа | двигунна | обсушити палубу в шторм |
| Прибирання | будь-де на палубі | прибрати плями (естетика + бонус до свіжості) |

### 4.4 Ловля риби
1. Вудка в кормі, E — **закинути** (поплавок за 8–14 м, залежно від рівня вудки).
2. Клев: 5–30 с (залежить від зони, погоди, звіту радіо, рівня вудки).
3. Клев! — спрайк + звук, 1.5 с на зачеп (E).
4. **Боротьба:** тяга лінії 0–100 %. Утримуй Space — підтягуєш (тяга росте), відпусти — риба тягне.
   Тяга > 90 % тривалий час — відрив (втрата риби). Відстань до 0 — улов!
5. Розмір ×0.7–1.5 → ціна. Риба потрапляє в трюм (обмеження — апгрейд).
- **Свіжість:** 100 → 0 за ~2 год гри; ціна ∝ свіжості. Варіння заморожує свіжість.
- **Зони:** узбережжя (мелюшки), середина, відкрите море (дорога риба, але далеко + небезпечно).

### 4.5 Погода
- Стани: **Тиша** → **Повіє** → **Вітер** → **Шторм**. Переходи плавні (~60 с),
  кожна 2–4 год гри.
- Шкала інтенсивності керує: амплітудою хвиль, вітром (зсув човна), хмарністю,
  дощем і блискавками (шторм), темрявою.
- Економіка ризику: у шторм рідкісна риба клює частіше, але палуба затоплюється,
  мотор працює гірше, ризик втрати корпусу.

### 4.6 Час і день
- Доба = 10 хв реального часу. Схід/захід, зорі, місяць, фарби неба/туману/світла.
- Вночі: прожектори човна (апгрейд «Світло»), маяк, вогні порту; риба клює інакше
  (деякі види — тільки ніч/день).

### 4.7 Економіка
- **Валюта:** ₴. Старт: 500 ₴.
- **Риба:** 12 видів (хамса → тунець → акула), 3 зони × денні/нічні вікна,
  ціни коливаються ±15 % на «тижні» (кожні 24 год гри).
- **Витрати:** паливо (20 ₴/л), ремонт у порту (100 ₴) / на човні (150 ₴ або час),
  апгрейди (6 дерев, 5 рівнів кожен).
- **Прибуток** = ціна × свіжість × розмір (×1.5 якщо варена).

### 4.5.1 Шторм — адреналінова петля
Шторм має бути **подією**, а не фоновим шумом:
- **Фаза 1 (передбачення):** радіо шипить, хвилі ростуть, хмари темнішають — гравець бачить
  горизонт і вирішує: дістати до дому зараз або ризикнути.
- **Фаза 2 (шторм):** хвилі ×2.5, дощ стіною, блискавки з гуркотом, бризки розбиваються об нос
  (сплески + тряска камери), палуба затоплюється → треба осушувати помпою, поки борешься з хвилями;
  велика хвиля може **заглушити двигун** (перезапуск з двигунної 2 с). Мотор гуде внапругу.
- **Фаза 3 (засідка в порту):** увірватися в порт — полегшення (тост «Серце на місці»),
  **штормовий бонус**: риба, заловлена в шторм/сильному вітрі, продається +25 % (мітка «штормовий улов»).
- Камера: м'яка тряска від ударів хвиль, нахил; звук: рев, гуркіт, стукіт по корпусу.

### 4.8 Апгрейди (кожен видно на лодці!)
> Правило: **жодного «невидимого» апгрейду** — кожне дерево змінює вигляд човна,
> звук або поведінку, і це помітно одразу після покупки.

| Дерево | Ефект | Візуал на лодці |
|---|---|---|
| Двигун | +20 % потужності/рівень | вищий вихлоп + глушник, подвійний вихлоп на 4+, дим, гучніший гул |
| Корпус | +40 міцності/рівень | сталева обшивка: на 2+ — бортові канти, 3+ — темніший колір, 5 — повна броня + кіل |
| Трюм | +6 місць/рівень | ящики і контейнер на палубі, мережа, на 5 — великий фреजर |
| Вудка | далі/швидше/міцніше | вудка довша й товща, на 2+ — бобіна, на 4+ — карбон + друга вудка |
| Паливний бак | +100 л/рівень | видно циліндри баків на палубі, на 5 — великий резервуар |
| Світло палуби | яскравіше/ширше | 1 фара → 4 ліхтарі по палубі + прожектор |
| Стабілізатор | −25 % крену за рівень | **стабілізаційні крила (foil)** по бортах: маленькі → великі крила на стійках |

### 4.9 Мета і прогресія
- Завдання: 1) перший продаж; 2) зловити всіх 12 видів; 3) дожити до шторму і повернутися з уловом;
  4) 5 рівнів у всіх деревах; 5) 25 000 ₴.
- Збереження: localStorage, автосейв кожні 30 с і при паузі.

## 6. Архітектура (для майбутнього коопу)

MVP — single-player, але код розшито під кооп:
- `World` (океан/погода/час) — єдине джерело правди, синхронізується по clock.
- `Boat` — один екземпляр на гру (кооп: shared object, authority — хост).
- `Player` — окремий клас на кожен слот (кооп: N слотів, інпути помередь).
- Станції — події `useStation(id)`, легко ретранслювати.
- Між тим: інтерфейс `NetworkAdapter { send, on }` запланований, MVP — `LocalAdapter`.

## 7. Перф (ціль: 60 FPS на середньому ноутбуці)
- Океан: 256×256 сегментів, все в vertex/fragment shader, 0 alloc на кадр.
- Обмеження: ≤ 100 draw calls, туман і frustum culling, one directional light + hemisphere.
- Частиці: пули (брізки, дощ, сплески), об'єктні пули без garbage.

## 8. Мінімальний MVP (цей реліз)
✅ Океан + погода + day/night, ✅ човен з фізикою і ходьбою, ✅ ловля (12 видів),
✅ порт (магазин/заправка/ремонт/хата), ✅ економіка + 7 апгрейдів (всі візуалізовані на лодці),
✅ шторм як подія (блискавки, затоплення, заглушення двигуна, штормовий бонус), ✅ станції та рутини,
✅HUD/меню/збереження/аудіо (синтез, без зовнішніх асетів), ✅ мінімапа-радар, ✅ мети.
❌ (далі) кооп, мультичовновість, торгові NPC, сезони, мобільний тач-контрол.
