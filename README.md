# Storm Fishers ⛵🎣

Затишна браузерна гра про риболовлю на вітрильній яхті (Three.js + TypeScript + Vite).

- вітрильна яхта з фізикою (кіль, вітрила, мотор, шторми за Бофортом)
- прозора вода з переломленням, хвилі до 14 м у відкритому морі
- риболовля-мінігра: закид із силою, підсічка, боротьба з рибою; стійки для кількох вудок
- фізична риба в ящику, біржа риби, апгрейди-деталі на човні, страховка
- кооп: спільна яхта для кількох гравців

## Запуск

```bash
npm ci
npm run dev        # http://localhost:5173 (кооп-реле на тому ж порту: /net)
```

Збірка: `npm run build` → `dist/`.

Кооп потребує WebSocket-реле (`server/relay.mjs`): `npm run serve` збирає гру й запускає сервер із реле.
Статичний хостинг (GitHub Pages / Vercel) — лише одиночна гра.
